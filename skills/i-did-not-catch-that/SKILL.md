The topic at hand, or your message was not understood by the user.
Give them an explanation using a little bit of context, talk in ASD-STE100 Simplified Technical English and use domain relevant language from agreed upon vocabulary (if available).
If this is an ongoing conversation, the user might be revisiting it after some time had passed.
